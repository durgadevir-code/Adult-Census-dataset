Adult Census Income Prediction – ML Project

Project Overview

- This project uses the Adult Census Income Dataset to predict whether a person's annual income is <=50K or >50K using machine learning.
  
Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
  
Project Steps

1. Load the dataset.
2. Clean the data and handle missing values.
3. Perform data visualization (EDA).
4. Preprocess numerical and categorical data.
5. Select important features.
6. Split data into training and testing sets.
7. Train machine learning models.
8. Evaluate model performance.
   
Machine Learning Algorithms

- Logistic Regression
- Decision Tree
- Random Forest
  
Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
  
Conclusion

- The project compares three machine learning algorithms to predict income categories and identifies the best-performing model based on evaluation results.
